## Командный тариф «Команда» — 25 000 ₽/мес, до 5 пользователей

### Цена и лимиты
- **25 000 ₽/мес**
- До **5 пользователей** (1 владелец + 4 участника)
- **Без ограничений** по числу расшифровок
- **До 100 часов** аудио в месяц на команду (общий пул)
- Общая история расшифровок, папки и теги внутри команды
- Все функции «Про» (AI-суммаризация, приоритетная поддержка)

### Модель данных (миграция БД)

1. Добавить значение `team` в enum `subscription_tier`.
2. Таблица `teams`: `name`, `owner_id`, timestamps.
3. Таблица `team_members`: `team_id`, `user_id`, `role` (`owner`/`member`), `joined_at`. Уникальный индекс на `user_id` (один пользователь — одна команда).
4. Таблица `team_invitations`: `team_id`, `email` (нормализованный), `token`, `invited_by`, `expires_at`, `accepted_at`.
5. На `subscriptions` — добавить nullable `team_id`. Для командного тарифа подписка привязывается к команде.
6. На `transcriptions`, `folders`, `tags` — добавить nullable `team_id`. Если задан, запись принадлежит команде и видна всем её участникам.
7. Таблица `team_usage` (агрегаты для месячного лимита команды).

### RLS-политики

- Security definer функция `get_user_team_id(user_id)` — без рекурсии.
- Security definer функция `is_team_owner(user_id, team_id)`.
- `transcriptions`/`folders`/`tags`: SELECT/INSERT/UPDATE/DELETE разрешены, если `user_id = auth.uid()` или `team_id = get_user_team_id(auth.uid())`.
- `teams`: SELECT для участников; UPDATE/DELETE — только владелец.
- `team_members`: SELECT для участников; INSERT/DELETE — только владелец.
- `team_invitations`: чтение/создание/удаление — только владелец; приём — через RPC по токену.

### Лимиты и квоты

- Обновить `can_user_transcribe`: для командного тарифа считать общий счётчик команды (лимит 100 расшифровок/мес).
- Edge function `elevenlabs-transcribe`: при сохранении расшифровки проставлять `team_id`, если пользователь в команде; инкрементировать `team_usage`.

### Платёж

- `yookassa-create-payment`: добавить tier `team` = 2 500 000 копеек (25 000 ₽).
- `yookassa-webhook`: при первой успешной оплате `team`-тарифа автоматически создать `teams` (владелец = плательщик), вставить `team_members` как owner, привязать `subscriptions.team_id`.

### UI

1. **Pricing**: 4-я карточка «Команда» (25 000 ₽/мес, 5 пользователей, общая история).
2. **`/team`** — управление командой (только владелец):
   - Название команды (редактируемое).
   - Список участников с кнопкой «Удалить».
   - Поле «Пригласить по email» → создаёт `team_invitation`, показывает ссылку `/team/join?token=...` для копирования.
   - Список pending-приглашений с возможностью отозвать.
3. **`/team/join`** — приём приглашения по токену (если не залогинен → редирект на `/auth` с возвратом).
4. **История** — переключатель «Мои / Команды» (если пользователь в команде).
5. **Account** — статус «Участник команды X (роль)» + кнопка «Выйти из команды» для участника (не владельца).
6. **Навигация** — пункт «Команда» для пользователей с командной подпиской.

### Технические детали

- Хук `useTeam()` — текущая команда, роль, список участников.
- `useSubscription()` обновить — учитывать командный тариф, показывать пул использования.
- `useTranscriptionQueue` / `transcriptionStorage`: проставлять `team_id` при сохранении.

### Что НЕ делаем сейчас
- Pro-rated биллинг при изменении состава.
- Роли сложнее `owner/member`.
- Передача владельца другому участнику.
- Несколько команд у одного пользователя.
- Email-доставка приглашений (на этой итерации — копируемая ссылка в UI).

### Объём
~12–15 файлов, одна миграция, две edge function правки. Выполняется в один проход.
