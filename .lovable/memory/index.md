# Project Memory

## Core
LexScribe: юридическая расшифровка аудио. Темно-синий + золотой. Playfair Display + Source Sans 3.
Lovable Cloud (Supabase) для бэкенда. ElevenLabs scribe_v2 для STT.
Русский язык интерфейса. Без ограничений на размер файлов.
