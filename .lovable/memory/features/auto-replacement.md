---
name: Автозамена с подтверждением
description: После расшифровки система ищет совпадения по правилам пользователя и предлагает заменить с подтверждением
type: feature
---
Реализована система автозамены с подтверждением (вариант 2):
- Таблица replacement_rules хранит правила (find_text → replace_text) per user с RLS
- Кнопка настроек (шестерёнка) в хедере главной страницы — модалка для CRUD правил
- После завершения расшифровки автоматически ищутся совпадения
- Панель подтверждения: пользователь выбирает какие замены применить (чекбоксы)
- Применённые замены обновляют сегменты локально
