type: feature

На странице History реализованы:
- **Папки** (`folders`): название + номер дела + цвет. Сайдбар слева, drag-free перемещение через popover «FolderInput». Папка может быть удалена — расшифровки внутри становятся «без папки».
- **Теги** (`tags`): универсальные метки с цветом. Связь many-to-many через `transcription_tags`. Управляются inline в карточке и в шапке открытой расшифровки через компонент `TagManager`.
- **Глобальный поиск**: RPC `search_transcriptions_advanced` ищет по тексту всех сегментов пользователя с фильтрами (папка, теги, спикер, номер дела, диапазон дат). Возвращает `match_count` и `first_snippet`. Результаты показываются прямо в списке с подсветкой количества совпадений и сниппетом.
- **Файлы**: `src/lib/foldersTagsStorage.ts`, `src/components/FolderSidebar.tsx`, `src/components/TagManager.tsx`. История переработана с двухколоночным макетом (sidebar + content).
