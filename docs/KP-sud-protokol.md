## 1. Предмет предложения

Предоставление доступа к облачному программному обеспечению **«ПротоколЪ»** для автоматической расшифровки аудиозаписей судебных заседаний с разделением реплик по участникам (диаризация), сохранением текста и возможностью экспорта в удобных для аппарата суда форматах.

Решение предназначено для **всех залов** [НАЗВАНИЕ СУДА] в рамках одного договора и единого пула часов.

---

## 2. Что получает суд

1. **Автоматическая расшифровка** аудио заседаний (русский язык).
2. **Разделение спикеров** (судья, стороны, свидетели и др. — по голосам в записи).
3. **Личные кабинеты** для сотрудников аппарата (секретари / помощники) — до **30 учёток** в пакете (с запасом под все составы).
4. **Хранение аудио и текста** в течение **180 дней** (по согласованию — дольше).
5. **Экспорт** результата (текст / структурированный протокол) для дальнейшей работы.
6. **Обучение** сотрудников — 1–2 онлайн-сессии при старте.
7. **Ежемесячный отчёт** по использованным часам аудио.
8. **Приоритетная поддержка** по каналу, согласованному в договоре (мессенджер / e-mail / телефон).

> Условия отличаются от публичных тарифов для частных пользователей: выделенный пул часов, расширенное хранение, несколько учёток, отчётность и сопровождение под нужды суда.

### 3.4. Экономический эффект для Заказчика (ориентир)

Ручная расшифровка 1 часа аудио заседания обычно занимает **3–5 часов** работы секретаря (набор + правка).  
При **800 часах** аудио в месяц это **2 400–4 000 человеко-часов** «в лоб».

С «ПротоколЪ» типичный сценарий: система даёт черновик → сотрудник правит.  
Экономия времени аппарата — порядка **50–70%** на этапе расшифровки.

| Показатель | Оценка |
|---|---|
| Зарплата секретаря судебного заседания (Оренбургская обл., ориентир вакансий) | ≈ 31–41 тыс. ₽ / мес |
| Полная стоимость часа работы сотрудника для учреждения (с начислениями, грубо) | ≈ 300–400 ₽ |
| Эквивалент сэкономленного труда при 50% экономии на 800 ч аудио | **≈ 400–700+ тыс. ₽ / мес** |
| Стоимость пакета «ПротоколЪ» | **300 тыс. ₽ / мес** |

Итого для суда: пакет окупается за счёт экономии труда аппарата и разгрузки секретарей; цена пакета **ниже**, чем эквивалент содержания **нескольких** дополнительных ставок под ручную расшифровку.

## 4. Порядок работы

1. Сотрудник суда загружает аудиозапись заседания в личный кабинет (или по согласованному каналу обмена файлами).
2. Система выполняет расшифровку и разделяет реплики по спикерам.
3. Сотрудник проверяет / правит текст и выгружает результат для оформления протокола.
4. Использованные часы списываются из месячного пула; в отчёте виден остаток.

Срок обработки типичной записи — существенно быстрее ручной расшифровки (зависит от длины файла и загрузки). Точные SLA по времени готовности фиксируются в договоре.

## 5. Конфиденциальность, доступ и режим работы с материалами

### 5.1. Учётные записи (не один общий логин)

| Роль | Сколько | Зачем |
|---|---|---|
| Администратор суда | 1–2 | приглашает сотрудников, видит отчёт по часам |
| Секретари судебных заседаний / помощники | до 28 (всего до **30** учёток) | каждый со **своим** логином; обычно ≈ по числу составов судей |

**Общий один аккаунт на весь суд не выдаём** — нельзя понять, кто загрузил дело; нельзя отозвать доступ у уволенного; выше риск утечки пароля.

Рекомендуемый порядок:
1. Создаётся команда суда (owner — ответственный от аппарата / ИТ).
2. Секретарям — персональные приглашения.
3. При увольнении / переводе — доступ отключается в тот же день.
4. По возможности — корпоративные e-mail (`@sudrf.ru` / служебные), не личные `@mail` / `@yandex`.

### 5.2. Конфиденциальность расшифровок

В договоре / приложениях фиксируется:

1. **Назначение:** аудио и текст используются только для подготовки протоколов Заказчика, не для обучения моделей Исполнителя и не для рекламы.
2. **NDA (соглашение о конфиденциальности)** — отдельным приложением.
3. **Поручение на обработку ПДн** (152-ФЗ) — если суд выступает оператором, а сервис — обработчиком.
4. **Закрытые заседания / материалы под грифом:** по умолчанию в облако **не загружаются**, либо только по письменному решению председателя / ответственного; отдельный регламент Заказчика.
5. **Срок хранения:** 180 дней, далее автоудаление аудио (текст — по согласованию); досрочная очистка — по запросу суда в согласованный срок (например, 5–10 рабочих дней).
6. **По окончании договора:** полная выгрузка (если нужно) + уничтожение данных у Исполнителя с актом.
7. **Запрет передачи** третьим лицам без согласия Заказчика, кроме технически необходимых субпроцессоров, перечисленных в договоре.

### 5.3. Что ещё важно согласовать до пилота

| Тема | Вопрос к суду | Как закрыть |
|---|---|---|
| Кто отвечает за загрузку | Секретарь зала / помощник судьи? | Список ФИО + учётки |
| Закрытые дела | Можно ли вообще в облако? | Регламент: только открытые / или запрет |
| Где живут данные | РФ / облако / субпроцессоры STT | Честно указать в договоре цепочку обработки |
| После расшифровки | Нужен ли архив в облаке? | Часто: скачали → удалили из сервиса |
| Журнал действий | Кто что загрузил? | Персональные учётки + отчёт по часам |
| Интернет в зале | Есть ли стабильный канал для upload? | Иначе — загрузка с рабочей станции аппарата |
| Формат аудио | Что пишет АСФ / диктофон? | Согласовать поддерживаемые форматы |
| Ответственный от суда | Одно контактное лицо | Для инцидентов и удаления данных |
| Инцидент утечки | Кого уведомлять, в какой срок | Прописать в NDA / договоре |

### 5.4. Важное ограничение (честно)

Расшифровка сейчас идёт через внешний STT-провайдер. Для суда это нужно **прямо указать в договоре** (субпроцессор) и получить согласие Заказчика.  
Если суд потребует «данные не покидают контур РФ / не уходят к иностранным сервисам» — это **отдельный проект** (другой контур / on-prem / российский STT), не текущий публичный SaaS. Пилот лучше начинать на **открытых** заседаниях без чувствительных материалов.

## 8. Почему это выгодно аппарату суда

- **Экономия времени:** черновик протокола за минуты вместо часов ручного набора с аудио.
- Один пакет на **все залы** — без россыпи подписок «как у частников».
- Прозрачный лимит часов и ежемесячная отчётность — удобно для сметы и обоснования расходов.
- Стоимость пакета сопоставима с **долей ФОТ** аппарата, а эффект — на объём, который вручную закрыть невозможно без расширения штата.
- Можно начать с **пилота**, измерить экономию на своих записях, затем зафиксировать основной договор.
